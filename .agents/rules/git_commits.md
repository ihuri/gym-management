# Regra de Commits

- **Confirmação e Edição Obrigatória**: NUNCA executar `git commit` ou criar commits automaticamente.
- **Fluxo de commit**:
  1. Apresentar o resumo das alterações e uma sugestão de mensagem de commit (no padrão Conventional Commits em português do Brasil).
  2. Solicitar ao usuário a aprovação ou edição da mensagem de commit (ex: "Deseja aprovar esta mensagem ou prefere editá-la?").
  3. Somente executar `git commit` após a mensagem final ser aprovada/informada pelo usuário.
