# Regra de Commits

- **Confirmação prévia obrigatória**: NUNCA executar `git commit` ou criar commits automaticamente.
- **Fluxo de commit**:
  1. Apresentar o resumo das alterações e a mensagem de commit sugerida (Conventional Commits em pt-BR).
  2. Perguntar ao usuário se autoriza a execução do commit.
  3. Somente executar `git commit` após resposta positiva do usuário.
